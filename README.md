# Agrowill Biotech - Static Website UI

A modern, clean, and fully responsive static website UI for **Agrowill Biotech**, an emerging biotechnology startup dedicated to cultivating premium medicinal fungi (Cordyceps) using modern scientific techniques and controlled growing environments.

## 🚀 Overview
This repository contains the frontend UI code for Agrowill Biotech's corporate and product website. The design emphasizes scientific precision, high-end sustainable packaging, and a commitment to quality and transparency.

* **Design Style:** Minimalist, card-based layout with high-quality spacing, sticky navigation, and professional forest green branding (`#1B4D3E`) paired with clean cream/white backgrounds.
* **Tech Stack:** HTML5, Tailwind CSS, and vanilla JavaScript (UI-only, no backend or database required).

---

## 📂 Website Structure & Pages

1. **Global Components**
   * **Navigation Bar:** Features the Agrowill Biotech logo, main menu links, and a prominent "Request Quote" action button.
   * **Footer:** Contains quick links, product categories, industry applications, support pages, newsletter subscription, and copyright information.

2. **Core Pages**
   * **Home Page:** Hero section with value propositions ("Science Driven. Nature Powered. Globally Trusted"), trust badges, key performance metrics, and core highlights.
   * **About Us Page:** Company background, core values (Integrity, Quality, Innovation, Sustainability, Reliability, Customer Commitment), and corporate vision & mission.
   * **Products & Product Detail Page:** Showcases product variations like *Whole Fruiting Body*, *Cordyceps Powder*, and *Cordyceps Extract*, complete with moisture specs, shelf life details, and packaging options.
   * **Cultivation & Quality Assurance Page:** Step-by-step scientific cultivation timeline (Mother Culture to Harvest & Drying) and strict quality control checkpoints accompanied by certifications (ISO, HACCP, GMP, HALAL).
   * **Industries We Serve & Global Export Page:** Tailored solutions for pharmaceuticals, nutraceuticals, wellness brands, and research institutions alongside global shipping highlights.
   * **Innovative Packaging Solutions:** Showcases next-generation sustainable packaging, including Miron violet glass jars, plantable zero-waste pouches, and industrial eco-composite bulk containers.
   * **Blog & Insights:** Articles detailing the health benefits and future of functional mushrooms.
   * **Contact Us Page:** Integrated corporate contact information (Jaipur address, emails, phone numbers) paired with a fully responsive inquiry form for B2B buyers.

## 🛠️ Getting Started / Local Setup

1. Clone or download this repository to your local machine.
2. Open the project folder in your code editor (e.g., VS Code).
3. Open `index.html` (or your entry file) using a live server extension (such as **Live Server** in VS Code) to view the UI preview locally.

---

## 📦 Assets & Customization
* **Logo & Imagery:** Place your official brand assets (logo, product packaging photos, and mockups) inside an `/assets` or `/images` folder and link them directly within your HTML code.
* **Styling:** Tailwind CSS classes control the visual presentation. You can modify the primary color schemes or fonts directly within your Tailwind configuration file or style block.
